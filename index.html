The problem being worked on

Fragmented market data

Retail feeds drop WebSocket connections during volatility spikes, exactly when order-book depth matters most. Reconstructing a clean tick history afterwards is slow and often impossible.

No place to run it

Collectors and execution workers need to sit close to venues and stay up unattended. A single machine under a desk in Santiago holds 9.45 GB of collected market data and runs every collector — the binding constraint on all nine prototypes.

What Azure would change

Compute near the venues

Virtual machines in US East and West Europe to host data collectors and execution workers, instead of one residential connection in South America.

Storage for the data bank

Blob Storage and Cosmos DB to migrate the existing 9.45 GB — 3,023 datasets across five venues — and keep collecting past what local disks can hold.

Containers and observability

Container Instances for isolated strategy workers, with Azure Monitor and Application Insights for socket latency and execution metrics.

Azure OpenAI

A natural-language layer over market microstructure data, so research questions can be asked in plain terms instead of hand-written queries.
